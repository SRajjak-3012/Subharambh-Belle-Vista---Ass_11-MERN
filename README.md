# How to Deploy a Website on GitHub Pages:
Step 1: Create a New Repository Go to GitHub and click New Repository.

Enter the Repository Name.

Add a short Description of your project.

Choose the repository visibility:

Public – anyone can view the repository. Private – only authorized users can access it. Select Add a README file. It is useful for documenting your project.

Click Create Repository.

Step 2: Upload Project Files Open your newly created repository.

Upload all required project files, such as:

index.html style.css script.js Images and other assets Update the README.md file if required.

After making any changes, always Commit Changes to save them to the repository.

Step 3: Configure Repository Settings Go to Settings of the repository. Check the Repository Name and change it if necessary. Make sure the default branch is set to main. Step 4: Configure GitHub Pages In Settings, go to Pages.

Under Build and deployment, select:

Source: GitHub Actions Select the Static HTML workflow.

Click Configure.

Step 5: Create and Commit the Workflow GitHub will automatically open the workflow configuration page. A .yml file will be created. You can rename the .yml file if required. Click Commit Changes. Step 6: Check the Deployment Status Go to the Actions tab of your repository.

Find the deployment workflow.

Check the status:

🟡 Yellow Dot: Deployment is still in progress. Wait until it finishes. 🟢 Green Tick: Deployment completed successfully. 🔴 Red Mark: Deployment failed; check the workflow logs for errors. Step 7: Visit Your Website Return to Settings → Pages. Under the deployment section, click Visit Site. Verify that your website is working correctly. Copy the website URL and share it with others. Deployment Complete! 🎉 Your static website is now deployed and accessible through GitHub Pages.
